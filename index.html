04 — SETUP GUIDE

Setup in minutes.
Ready from first boot.

Follow the steps below to activate JackOS, create accounts and complete the initial setup process.

STEP 01

Activate JackOS

Enter your activation key to unlock all JackOS features, including Cloud Sync.

If you do not have an activation key, you may continue using:

GUES-TACT-IVAT-ION

Systems activated using this key operate with reduced functionality and certain features may be unavailable.

STEP 02

Check Existing Accounts

If JackOS detects a previous installation, you can log into the existing administrator account and continue directly to login.

Choosing No or having no existing accounts will start the full setup process.

STEP 03

Create User Accounts

Create one or more user accounts. The first account automatically becomes the administrator account.

Additional standard and guest accounts can be created later and permissions can be modified at any time.

STEP 04

Configure Security Questions

Select three security questions and provide answers for each user account.

These are used to verify identity and assist with account recovery if a password is forgotten.

LOGIN

Sign In

After setup is complete, choose your account and enter your password to continue.

Once verified, JackOS will load your desktop environment and restore your saved settings.

✓

Setup Complete

Welcome to JackOS. Your system has been successfully configured and is now ready to use.
